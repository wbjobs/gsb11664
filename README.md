# 复杂表单快照与时间旅行

纯原生技术实现（无框架）：IndexedDB + DOM + Web Worker + Canvas。

## 运行

需要通过 HTTP 访问（Web Worker 与 IndexedDB 在 `file://` 下受限）：

```bash
cd 本目录
python3 -m http.server 8080
# 打开 http://localhost:8080
```

## 功能

- **复杂表单**：4 个分组，涵盖文本/数字/日期/下拉/单选/多选/多行文本，以及可动态增删行的「项目成员」重复组。
- **快照**：任意时刻创建、命名、重命名、删除；Canvas 时间线可视化（点大小反映压缩率，颜色区分手动/自动备份/冲突/导入）。
- **快照对比**：任选两个快照，按字段路径展示新增/删除/变更。
- **回滚**：回滚前自动备份当前未保存修改（不丢数据）；若当前修改与目标快照分叉，标记为「冲突备份」。
- **时间旅行回放**：按时间顺序自动播放或单步前进/后退，变更字段高亮闪烁，可调速。
- **导出/导入**：JSON 文件含格式版本与整体校验和；导入时自动迁移旧版本、检测冲突。

## 关键约束实现

| 约束 | 实现 |
| --- | --- |
| 压缩不丢数据 | Worker 内 WTF-8 风格 UTF-8 + LZW（字典重置码防 16 位溢出），压缩后立即回读校验，失败回退原始存储 |
| 冲突检测 | 每个快照带 cyrb53 内容哈希；回滚时检测当前修改与目标分叉；导入时同 id 不同哈希保留双方 |
| 回滚不丢数据 | 回滚前自动创建当前状态的备份快照 |
| 字段增删/类型变化 | 状态带 `__v` 版本，迁移链逐级升级；恢复时按当前 schema 做类型矫正；已删除字段进入 `_legacy` 保留展示 |
| 版本兼容 | 快照带 `formatVersion`/`schemaVersion`；高版本文件降级为尽力读取；低版本自动迁移 |
| 状态可序列化 | 状态为纯 JSON，规范序列化（key 排序）保证哈希稳定；当前编辑内容实时持久化到 IndexedDB，刷新不丢 |

## 文件结构

- `index.html` — 页面结构
- `css/style.css` — 样式
- `js/schema.js` — 表单结构、默认值、状态迁移、类型矫正、diff
- `js/db.js` — IndexedDB 封装（snapshots + kv 两个仓库）
- `js/worker.js` — Web Worker：无损压缩/解压 + 哈希
- `js/snapshot.js` — 快照管理：创建/校验/恢复/导入导出
- `js/form.js` — 表单渲染与 DOM ↔ 状态转换
- `js/timeline.js` — Canvas 时间线
- `js/app.js` — 主控装配
